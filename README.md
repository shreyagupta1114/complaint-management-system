PG & Apartment Complaint Management System
1. Project Overview
The PG & Apartment Complaint Management System is a web-based application designed to make the process of submitting,
 managing, and tracking resident complaints easier and more organized.
Residents can submit complaints related to issues such as plumbing, electricity, maintenance, cleanliness, etc.
The admin can view all complaints and update their status as the issue is being handled.
The project demonstrates the use of HTML, CSS, JavaScript, Node.js, Express.js, REST APIs, Sequelize, and MySQL.

2. Problem Statement
In a PG or apartment environment, complaints are often communicated informally through messages or verbally.
This can make it difficult to track complaints, identify pending issues, and know whether an issue has been resolved.
This project provides a centralized system where:
i.Residents can submit complaints.
ii.Residents can view their complaints.
iii.Complaints can be categorized and assigned a priority.
iv.Admins can view all complaints.
v.Admins can update complaint status.
vi.Complaints can be updated or deleted.
vii.Residents can provide a rating/review after a complaint is handled.

6. Conclusion
The project provides a simple and functional solution for managing PG and apartment complaints.
The main focus of the implementation was understanding the problem, designing appropriate frontend and backend components, implementing REST APIs, handling CRUD operations, and connecting the frontend with the backend.
MySQL and Sequelize were additionally integrated to provide persistent data storage and demonstrate database integration.
The project was tested using Postman and the API testing evidence has been included in the GitHub repository.
